# Data Folder

Place the official competition files here when running the project locally.

Expected local structure:

```text
data/
├── images/
│   ├── party_list_34_11.png
│   ├── party_list_34_11_page2.png
│   └── ...
└── submission_template_v4.csv
```

The full image dataset is not included in this GitHub repository because it contains 846 PNG page images and is large.

Only a few sample images are included under:

```text
assets/sample_images/
```

The `data/images/` folder is ignored by `.gitignore`.
